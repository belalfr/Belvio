How a project runs.

Four stages, always in this order. You see the baseline before I touch anything.

GET /processcrawled ✓ indexed ✓

Crawl

Every page I can reach gets checked for status codes, speed, titles, headings, links and indexing. That snapshot is the baseline everything else is judged against.

Diagnose

Not all errors matter. I sort what I find by how likely it is to hold your pages back, so you fix the expensive things first.

Fix

Small batches, written down. If a change helps, you can see which one. If it hurts, it can be undone exactly.

Re-check

I run the same checks again and show you the before and after side by side. If nothing moved, the report says so.
